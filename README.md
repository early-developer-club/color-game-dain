# 🎨 절대색감 게임

## 📖 프로젝트 소개
화면에 보이는 여러 개의 네모 중에서 색이 다른 하나를 찾는 절대색감 게임입니다. 60초 안에 최대한 많은 단계를 완료하는 도전적인 웹 게임입니다.

## ⏱️ 바이브코딩 소요 시간
- **시작**: 2025년 09월 27일
- **소요 시간**: 약 2시간
- **총 메시지**: 24개 프롬프트

## 🛠️ 기술 스택
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **배포**: Vercel
- **반응형**: 모바일 우선 설계
- **애니메이션**: CSS3 Transitions, JavaScript

## 🎮 게임 기능
- **30단계 난이도**: 점진적으로 어려워지는 곡선형 난이도
- **시간 제한**: 60초 타이머
- **페널티 시스템**: 틀리면 3초 감소 + 화면 흔들림
- **최고 점수**: 로컬 스토리지에 저장
- **반응형 디자인**: 모바일/데스크탑 최적화

## 🚀 배포 정보
- **URL**: https://color-game-dain.vercel.app/
- **배포 플랫폼**: Vercel
- **소셜 공유**: Open Graph, Twitter Card 지원

## 📝 바이브코딩 핵심 기록 (16개 주요 프롬프트)

### 1. **"절대색감 게임 웹 서비스를 만들고싶어. 절대색감 게임은 화면에 보이는 여러개의 네모 중에서 색이 다른 하나를 찾는 게임이야. 단계가 올라갈 수록 네모의 개수가 늘어나고 색상간의 차이가 적어서 알아보기 힘들어져. 정답을 찾았을 때 다음 단계로 넘어가고, 60초 이내에 더 많은 단계로 나아가는 게임이야. 첫 화면은 간단한 게임 룰 설명을 포함했으면 좋겠어. 게임이 종료되면 도달한 단계를 포함한 게임 결과화면도 노출시켜줘. 모바일 웹을 기준으로 만드는데, 데스크탑에서도 적당히 잘 보이도록 만들어줘."**
- **처리 내용**: 기본 HTML, CSS, JavaScript 파일 생성
- **구현**: 게임 룰 설명 화면, 게임 화면, 결과 화면
- **기능**: 색상 네모 생성, 정답 찾기 로직, 60초 타이머

### 2. **"지금은 틀리면 게임이 바로 종료되는데, 틀려도 게임은 계속되어야해. 같은 단계에서도 몇번이든 시도할 수 있고 정답을 맞추었을 때 다음 단계로 넘어가. 60초가 지났을 때에만 게임이 종료되는거야. 그리고, 지금 네모가 너무 얇아서 선처럼보여. 정사각형으로 만들어줘."**
- **처리 내용**: 게임 로직 수정, 네모 크기 개선
- **구현**: 틀려도 게임 계속 진행, 정사각형 네모 생성
- **기능**: 무제한 재시도, 정답 시에만 다음 단계

### 3. **"지금 네모를 배치할 때 빈 공간이 생기거든. 예를 들어 2 * 2 배치인데 3개만 있어서 마지막 칸이 비는 것 처럼 말이야. 네모의 개수는 n * n 의 제곱수로 해서 빈 공간이 없게 해줘. 마지막 결과 페이지에서 남은 시간은 항상 0초 이므로, 남은 시간 부분을 제거해줘. 지금까지 시도한 최고 점수를 노출해도 좋을 것 같아."**
- **처리 내용**: 네모 개수를 제곱수로 변경, 결과 화면 개선
- **구현**: 4, 9, 16, 25, 36... 순으로 네모 개수 증가
- **기능**: 최고 점수 시스템, 빈 공간 제거

### 4. **"초반부터 난이도가 너무 높아. 초반에는 정답 색상과 다른 색 사이의 차이를 좀 더 키워줘. 색상을 선택했을 때 애니메이션 때문인지 딜레이가 좀 있는 것 같아. 불필요한 애니메이션을 제거해서 속도감 있게 플레이할 수 있게 해줘. 디자인 관련해서, 그라데이션 디자인을 선호하지 않아서, 채도가 낮고 밝은 깔끔한 톤의 디자인으로 수정해줘. 라운드도 너무 둥글둥글하지 않게 낮춰주고. 글씨 크기도 전체적으로 좀 줄여줘."**
- **처리 내용**: 난이도 조절, 애니메이션 제거, 디자인 개선
- **구현**: 초반 색상 차이 증가, 불필요한 애니메이션 제거
- **기능**: 그라데이션 제거, 채도 낮은 톤, 라운드 처리 감소

### 5. **"난이도 조절이 처음보다는 괜찮아졌는데, 갑자기 3단계에서 4단계로 너무 급격하게 어려워져. 색상을 rgb로 표현할 때 정답 색상을 (r1, g1, b1), 오답 색상을 (r2, g2, b2)라고 할 때. (r1-r2)^2, (g1-g2)^2, (b1-b2)^2 의 값이 점점 감소할 수 있도록 해줘. 단계가 오를수록 서서히 r g b의 편차가 줄어들어야한다는 말이야. 급격하지 않게."**
- **처리 내용**: RGB 색상 차이를 점진적으로 줄이는 시스템 구현
- **구현**: HSL → RGB 색상 시스템 변경, 고정된 차이값 사용
- **기능**: 1~30단계 확장, 점진적 난이도 조절

### 6. **"지금은 네모들 왼쪽에 시간이 표시돼. 위쪽에 뜨도록 수정해줘."**
- **처리 내용**: 시간 표시 위치 수정
- **구현**: 헤더와 네모 사이 빈 공간에 시간 배치
- **기능**: 라운드 배경 제거, 기울임꼴 텍스트

### 7. **"틀렸을 때 시간이 조금 감소하는 규칙을 추가하면 좋을 것 같아. 게임 방법에 추가하고, 틀렸을 경우 화면이 짧게 흔들리면서 시간이 감소하도록 해줘."**
- **처리 내용**: 시간 감소 규칙 추가, 화면 흔들림 효과
- **구현**: 틀리면 3초 감소, 화면 흔들림 애니메이션
- **기능**: 게임 방법 설명 추가, 시각적 피드백

### 8. **"흔들리는 애니메이션 지속 시간을 줄여줘. 흔들리고 나서 화면이 리로드되는 것 처럼 보이는데, 그 현상 수정해줘."**
- **처리 내용**: 흔들림 애니메이션 최적화
- **구현**: 0.5초 → 0.3초 단축, 화면 리로드 현상 해결
- **기능**: JavaScript 직접 제어, 깜빡임 현상 해결

### 9. **"배포해줘"**
- **처리 내용**: Vercel 배포 설정 및 실행
- **구현**: vercel.json 설정, 정적 파일 서빙
- **기능**: 프로덕션 배포, 도메인 생성

### 10. **"배포는 됐는데, 스타일도 하나도 적용이 안돼서 화면이 다 깨졌고, 어떠한 동작도 하지 않아."**
